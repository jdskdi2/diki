# Google Stitch

Google의 AI UI 생성 도구 (`stitch.withgoogle.com`). [[design-md]] 개념을 도입하고 공식 명명 Vibe Design (2026-03)을 발표했다.

## 역할

- **DESIGN.md 도입**: AI agent가 읽는 plain-text design system을 single source of truth로 제시.
- **Stitch skills**: `google-labs-code/stitch-skills`의 design-md skill — MCP로 화면·HTML/CSS 분석 → 자동 생성.
- **생태계**: VoltAgent `awesome-design-md` 컬렉션과 `getdesign.md` 배포가 실전 입문 경로 ([[design-md-google-stitch-guide]]).
