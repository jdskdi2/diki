# Cursor

AI 코딩 IDE의 대표 예시. CLI 에이전트와 비슷한 작업을 수행하지만 결과를 텍스트 로그 대신 diff·파일 구조로 시각적으로 확인하는 방식이다.

## 특징

- **인터페이스**: 코드 에디터. 실행 몸체는 에디터 내부 + 로컬 프로젝트 ([[ai-tools-study]]).
- **범위**: 자동완성 같은 짧은 도움부터 여러 파일에 걸친 작업("로그인 화면 하나 만들어줘")까지.
- **차별점**: 변경 사항을 눈으로 보면서 확인할 수 있다는 점이 CLI와의 체감 차이.
