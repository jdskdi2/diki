# Aside

브라우저 자체가 통째로 에이전트인 브라우저형 도구. 확장 프로그램이 아니라 브라우저 단위라 Gmail·사내 관리 도구 등 로그인된 사이트에 손이 닿는다.

## 특징

- **인터페이스**: 브라우저. 실행 몸체는 로그인해둔 웹페이지 자체 ([[ai-tools-study]]).
- **방식**: API 연동 없이 사람이 로그인해둔 사이트를 직접 클릭·입력하며 처리. 작업 난이도에 따라 사고·행동 깊이 단계 선택.
- **배경**: 한국인 3명이 창업한 팀의 제품이라는 소개 포함.
