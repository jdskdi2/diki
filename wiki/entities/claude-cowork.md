# Claude Cowork

Anthropic의 데스크톱 위임형 에이전트. 코드가 아니라 문서·스프레드시트·폴더 정리 같은 사무 업무를 대신 맡기는 도구다.

## 특징

- **인터페이스**: 데스크톱 앱. 실행 몸체는 로컬 파일 시스템 + 앱 ([[ai-tools-study]]).
- **용도**: "자료 취합해서 보고서로", "다운로드 폴더 정리" 같은 지시를 여러 파일을 오가며 하나의 결과물로 조립.
- **포지셔닝**: 코딩 에이전트와 같은 엔진을 비개발자도 쓸 수 있게 사무 업무에 맞게 감싼 형태. 같은 Claude라도 Chat·[[claude-code]]와 하네스가 다르다는 예시의 한 축.
