# Token-Maxxing

Token을 최대한 많이 쓰는 행위를 실력처럼 과시하는 문화. Looksmaxxing에서 온 `-maxxing` (끝까지 밀어붙이기)에서 유래했다.

## 역사

2025년 Claude Code 확산이 기폭제 → 2025-07 Shopify AI-first + 리더보드 (Farhan Thawar) → 변질 확산 (Meta `Token Legend`·`Cache Wizard` 칭호, Microsoft/Disney 대시보드, Tokscale) → 2026-05 Amazon 부풀리기 보도 → 2026-06 Uber cap → 2026-06-09 본 기사.

## 비판 3점 ([[end-of-token-maxxing]])

1. Token ≠ 산출물 (Uber 4달 예산 소진, 월 $2,000 → 성과 입증 불가).
2. Token ≠ 정직도 (Goodhart's law — 잣대가 목표가 되면 무효).
3. Token = 공급자 매출 (GPT-5.5 2배, Gemini 3.5 Flash 3배, Opus 4.7 tokenizer +35%).

## 대안

적게 쓰고 잘 쓰기 ([[context-engineering]] 최소 투입 원칙) + outcome-based evaluation ("그 한도로 무엇을 바꿨는지"). 한국 신조어 토성비 (토큰 가성비). 단 AI 도입 초기에는 리더보드가 "안 쓰면 도태" 압박용으로 유효했던 공로 인정.
