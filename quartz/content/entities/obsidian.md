# Obsidian

**마크다운 기반 Personal Knowledge Management 도구**. 로컬 파일 기반으로 동작하며, 노트 간 링크와 그래프 뷰를 제공함.

## LLM Wiki에서의 역할

LLM Wiki 패턴에서 Obsidian은 **위키를 탐색하는 IDE** 역할.

> "Obsidian is the IDE; the LLM is the programmer; the wiki is the codebase."

## 주요 기능

- **Graph View**: 노트 간 연결을 시각적으로 파악. 허브/고아 페이지 식별
- **Obsidian Web Clipper**: 웹 아티클을 마크다운으로 변환해 빠르게 소스 추가
- **Dataview 플러그인**: YAML frontmatter 기반 동적 쿼리 (최근 소스 목록 등)
- **Marp 플러그인**: markdown으로 슬라이드 덱 생성
- **로컬 파일 기반**: git으로 버전 관리 가능

## 팁

- Settings → Files & links → Attachment folder path: `raw/assets/` 설정
- "Download attachments for current file" 핫키 바인딩으로 이미지 일괄 다운로드
- Graph view로 위키 구조 모니터링
