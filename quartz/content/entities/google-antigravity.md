# Google Antigravity

Google의 AI 코딩 IDE. 에이전트 여러 개를 동시에 띄워 각자 다른 작업을 맡기고 진행 상황만 관리하는 방식을 지원한다는 점에서 소개된다.

## 특징

- **인터페이스**: 코드 에디터. 실행 몸체는 에디터 내부 + 로컬 프로젝트 ([[ai-tools-study]]).
- **차별점**: 단일 에이전트 작업이 아니라 **멀티 에이전트 병렬 위임** — 같은 IDE 유형 내에서 한 발 더 나아간 형태.
- **위치**: 자율성 중간~높음 구간 ([[ai-tool-autonomy-spectrum]]).
